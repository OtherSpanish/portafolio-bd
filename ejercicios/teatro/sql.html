Consultas sobre la base de datos (MySQL) con su resultado · Teatro.

Ver enunciado del ejercicio

Una red de teatros de Bogotá quiere manejar su cartelera, sus actores y la venta de boletas.

  • Cada TEATRO tiene un código, nombre, dirección y aforo.
  • Cada OBRA tiene un número, título, autor, duración y uno o varios géneros (drama, comedia, musical…).
  • Una FUNCIÓN es una presentación de una obra en un teatro, con fecha, hora y precio.
  • Cada ACTOR tiene identificación, nombre artístico y nombre real (nombres y apellidos). Un actor actúa en varias obras y en cada una hace un personaje. Algunos son cantantes (se guarda su registro vocal), otros bailarines (se guarda su estilo), hay quienes hacen las dos cosas y hay quienes no hacen ninguna.
  • Un actor puede ser el suplente de otro actor. Cada suplente cubre a un solo titular, pero un titular puede tener varios suplentes.
  • Cada ESPECTADOR tiene identificación, nombre (nombres y apellidos), fecha de nacimiento, correo y teléfonos; la edad se calcula. Un espectador compra boletas para varias funciones y en cada boleta va la fila y la silla.

Entidades base: Actor, Espectador y Teatro. Entidades inventadas para completar el problema: Obra y Función.

Consulta 1

Cartelera: cada función con su teatro, su obra y las boletas vendidas.

SELECT f.fecha, f.hora, t.nombre AS teatro, o.titulo, COUNT(b.documento) AS vendidas
FROM FUNCION f
JOIN TEATRO t ON t.codigo_teatro = f.codigo_teatro
JOIN OBRA o ON o.id_obra = f.id_obra
LEFT JOIN BOLETA b ON b.id_funcion = f.id_funcion
GROUP BY f.id_funcion, f.fecha, f.hora, t.nombre, o.titulo
ORDER BY f.fecha, f.hora;

Consulta 2

Cada actor con el actor al que suple.

SELECT s.nombre_artistico AS suplente, t.nombre_artistico AS titular
FROM SUPLENCIA x
JOIN ACTOR s ON s.id_actor = x.id_suplente
JOIN ACTOR t ON t.id_actor = x.id_titular
ORDER BY titular;

Consulta 3

Los géneros de cada obra en una sola columna.

SELECT o.titulo, GROUP_CONCAT(g.genero ORDER BY g.genero SEPARATOR ', ') AS generos
FROM OBRA o
JOIN OBR_GENERO g ON g.id_obra = o.id_obra
GROUP BY o.id_obra, o.titulo
ORDER BY o.titulo;

Consulta 4

Lo recaudado por cada obra con las boletas vendidas.

SELECT o.titulo, COUNT(*) AS boletas, SUM(f.precio) AS recaudo
FROM BOLETA b
JOIN FUNCION f ON f.id_funcion = b.id_funcion
JOIN OBRA o ON o.id_obra = f.id_obra
GROUP BY o.id_obra, o.titulo
ORDER BY recaudo DESC;

Consulta 5

Espectadores que han ido a más de una función.

SELECT e.nombres, e.apellidos, COUNT(*) AS funciones
FROM BOLETA b
JOIN ESPECTADOR e ON e.documento = b.documento
GROUP BY e.documento, e.nombres, e.apellidos
HAVING COUNT(*) > 1
ORDER BY funciones DESC;

Consulta 6

Actores que no cantan ni bailan.

SELECT nombre_artistico, nombres, apellidos
FROM ACTOR
WHERE tipo_actor IS NULL
ORDER BY nombre_artistico;
