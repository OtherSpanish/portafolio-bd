Ejercicio · Aeropuerto

Sentencias SQL

DDL, DML y consultas del aeropuerto, con resultados reales.

Ver enunciado del ejercicio

Una aerolínea que opera en varios aeropuertos de Colombia necesita una base de datos para su operación.

  • Cada BASE (aeropuerto donde la aerolínea tiene operación) se identifica con un código IATA de tres letras y tiene nombre, ciudad y país.
  • Cada PILOTO tiene identificación, nombre, número de licencia, horas de vuelo acumuladas y uno o varios teléfonos. Está asignado a exactamente una base.
  • Cada AVIÓN se identifica por su matrícula y tiene modelo, fabricante y capacidad. Permanece en una base.
  • Un VUELO tiene un identificador, un código comercial (por ejemplo AV101), fecha, hora de salida y destino. Sale de una base y lo opera un único avión.
  • En cada vuelo trabajan uno o más pilotos con un rol (capitán o copiloto), y un piloto puede tripular muchos vuelos.
  • Los PASAJEROS se registran con identificación, nombre (nombres y apellidos), fecha de nacimiento y correo; su edad se calcula. Un pasajero reserva vuelos y en cada reserva se guarda el asiento y la clase.

Entidades del enunciado: Piloto, Pasajero y Base. Entidades inventadas para completar el problema: Avión y Vuelo.

Script completo

Todo el ejercicio está en un solo archivo que crea las tablas e inserta los datos de prueba. Se probó en PostgreSQL 16 y usa SQL estándar (compatible con MySQL 8 salvo donde se indica).

DDLDDL · Creación de tablas

El orden importa: primero las tablas que no dependen de nadie (BASE, PERSONA) y después las que tienen llaves foráneas. Los DROP van en orden inverso.

Ver los DROP TABLE
DROP TABLE IF EXISTS reserva;
DROP TABLE IF EXISTS tripula;
DROP TABLE IF EXISTS vuelo;
DROP TABLE IF EXISTS avion_carga;
DROP TABLE IF EXISTS avion_comercial;
DROP TABLE IF EXISTS avion;
DROP TABLE IF EXISTS pasajero;
DROP TABLE IF EXISTS piloto;
DROP TABLE IF EXISTS telefono_persona;
DROP TABLE IF EXISTS persona;
DROP TABLE IF EXISTS base;

CREATE TABLE base (
    codigo_base  CHAR(3)      PRIMARY KEY,
    nombre       VARCHAR(80)  NOT NULL,
    ciudad       VARCHAR(50)  NOT NULL,
    pais         VARCHAR(50)  NOT NULL
);

CREATE TABLE persona (
    documento         VARCHAR(15)  PRIMARY KEY,
    nombres           VARCHAR(50)  NOT NULL,
    apellidos         VARCHAR(50)  NOT NULL,
    fecha_nacimiento  DATE         NOT NULL
);

-- Atributo multivaluado "telefono" de PERSONA
CREATE TABLE telefono_persona (
    documento  VARCHAR(15)  NOT NULL,
    telefono   VARCHAR(15)  NOT NULL,
    PRIMARY KEY (documento, telefono),
    FOREIGN KEY (documento) REFERENCES persona(documento) ON DELETE CASCADE
);

-- Subclase PILOTO (especialización de PERSONA)
CREATE TABLE piloto (
    documento    VARCHAR(15)  PRIMARY KEY,
    licencia     VARCHAR(10)  NOT NULL UNIQUE,
    horas_vuelo  INT          NOT NULL CHECK (horas_vuelo >= 0),
    codigo_base  CHAR(3)      NOT NULL,
    FOREIGN KEY (documento)   REFERENCES persona(documento) ON DELETE CASCADE,
    FOREIGN KEY (codigo_base) REFERENCES base(codigo_base)
);

-- Subclase PASAJERO (especialización de PERSONA)
CREATE TABLE pasajero (
    documento  VARCHAR(15)   PRIMARY KEY,
    correo     VARCHAR(80)   NOT NULL UNIQUE,
    millas     INT           NOT NULL DEFAULT 0 CHECK (millas >= 0),
    FOREIGN KEY (documento) REFERENCES persona(documento) ON DELETE CASCADE
);

CREATE TABLE avion (
    matricula    VARCHAR(10)  PRIMARY KEY,
    modelo       VARCHAR(40)  NOT NULL,
    fabricante   VARCHAR(40)  NOT NULL,
    codigo_base  CHAR(3)      NOT NULL,
    FOREIGN KEY (codigo_base) REFERENCES base(codigo_base)
);

-- Subclases de AVION (especialización disjunta y parcial)
CREATE TABLE avion_comercial (
    matricula     VARCHAR(10)  PRIMARY KEY,
    num_asientos  INT          NOT NULL CHECK (num_asientos > 0),
    FOREIGN KEY (matricula) REFERENCES avion(matricula) ON DELETE CASCADE
);

CREATE TABLE avion_carga (
    matricula     VARCHAR(10)    PRIMARY KEY,
    capacidad_kg  DECIMAL(10,2)  NOT NULL CHECK (capacidad_kg > 0),
    FOREIGN KEY (matricula) REFERENCES avion(matricula) ON DELETE CASCADE
);

CREATE TABLE vuelo (
    id_vuelo            INT          PRIMARY KEY,
    codigo              VARCHAR(8)   NOT NULL,
    fecha               DATE         NOT NULL,
    hora_salida         TIME         NOT NULL,
    destino             VARCHAR(50)  NOT NULL,
    matricula           VARCHAR(10)  NOT NULL,
    codigo_base_origen  CHAR(3)      NOT NULL,
    UNIQUE (codigo, fecha),
    FOREIGN KEY (matricula)          REFERENCES avion(matricula),
    FOREIGN KEY (codigo_base_origen) REFERENCES base(codigo_base)
);

-- Relación M:N PILOTO —TRIPULA— VUELO
CREATE TABLE tripula (
    documento  VARCHAR(15)  NOT NULL,
    id_vuelo   INT          NOT NULL,
    rol        VARCHAR(10)  NOT NULL CHECK (rol IN ('CAPITAN', 'COPILOTO')),
    PRIMARY KEY (documento, id_vuelo),
    FOREIGN KEY (documento) REFERENCES piloto(documento),
    FOREIGN KEY (id_vuelo)  REFERENCES vuelo(id_vuelo) ON DELETE CASCADE
);

-- Relación M:N PASAJERO —RESERVA— VUELO
CREATE TABLE reserva (
    documento  VARCHAR(15)  NOT NULL,
    id_vuelo   INT          NOT NULL,
    asiento    VARCHAR(4)   NOT NULL,
    clase      VARCHAR(10)  NOT NULL CHECK (clase IN ('ECONOMICA', 'EJECUTIVA')),
    PRIMARY KEY (documento, id_vuelo),
    UNIQUE (id_vuelo, asiento),
    FOREIGN KEY (documento) REFERENCES pasajero(documento),
    FOREIGN KEY (id_vuelo)  REFERENCES vuelo(id_vuelo) ON DELETE CASCADE
);

Lista de pasajeros del vuelo 1 con su asiento y clase.

SELECT r.asiento, pe.nombres, pe.apellidos, r.clase
FROM reserva r
JOIN persona pe ON pe.documento = r.documento
WHERE r.id_vuelo = 1
ORDER BY r.clase DESC, pe.apellidos;

SELECT 2LEFT JOIN + COUNT

Cuántos vuelos ha operado cada avión, incluidos los que no han volado.

SELECT a.matricula, a.fabricante, a.modelo, COUNT(v.id_vuelo) AS vuelos
FROM avion a
LEFT JOIN vuelo v ON v.matricula = a.matricula
GROUP BY a.matricula, a.fabricante, a.modelo
ORDER BY vuelos DESC, a.matricula;

Con JOIN normal la Cessna (HK-7001) desaparecería; LEFT JOIN la conserva con 0.

SELECT 4Subconsulta

Pilotos con más horas de vuelo que el promedio.

SELECT pe.nombres, pe.apellidos, pi.horas_vuelo
FROM piloto pi
JOIN persona pe ON pe.documento = pi.documento
WHERE pi.horas_vuelo > (SELECT AVG(horas_vuelo) FROM piloto)
ORDER BY pi.horas_vuelo DESC;

El promedio es (12500 + 6800 + 15200 + 2900) / 4 = 9350 horas.

SELECT 5CASE + LEFT JOIN a subclases

Tipo de cada avión según la especialización (comercial, carga u otro).

SELECT a.matricula, a.fabricante, a.modelo,
       CASE
           WHEN c.matricula IS NOT NULL THEN 'COMERCIAL'
           WHEN g.matricula IS NOT NULL THEN 'CARGA'
           ELSE 'OTRO'
       END AS tipo,
       c.num_asientos, g.capacidad_kg
FROM avion a
LEFT JOIN avion_comercial c ON c.matricula = a.matricula
LEFT JOIN avion_carga     g ON g.matricula = a.matricula
ORDER BY a.matricula;

Así se “reconstruye” la jerarquía AVION del MER-E a partir de las tablas de la estrategia A.

SELECT 6Ocupación por vuelo

Porcentaje de ocupación de los vuelos comerciales.

SELECT v.id_vuelo, v.codigo, v.destino, c.num_asientos,
       COUNT(r.documento) AS ocupados,
       ROUND(100.0 * COUNT(r.documento) / c.num_asientos, 2) AS porcentaje
FROM vuelo v
JOIN avion_comercial c ON c.matricula = v.matricula
LEFT JOIN reserva r    ON r.id_vuelo = v.id_vuelo
GROUP BY v.id_vuelo, v.codigo, v.destino, c.num_asientos
ORDER BY v.id_vuelo;

VIEWVista para el atributo derivado edad

La edad del MER es un atributo derivado: no se guarda en la tabla para que nunca quede desactualizada. Se calcula con una vista.

CREATE VIEW v_persona_edad AS
SELECT documento, nombres, apellidos, fecha_nacimiento,
       EXTRACT(YEAR FROM AGE(CURRENT_DATE, fecha_nacimiento)) AS edad
FROM persona;

SELECT * FROM v_persona_edad ORDER BY edad DESC;

En MySQL la edad se calcula con TIMESTAMPDIFF(YEAR, fecha_nacimiento, CURDATE()). El resultado cambia con la fecha; este se generó el 15/11/2026.
